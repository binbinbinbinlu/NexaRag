# Nexa Demo IT support guide

FICTIONAL TEST DATA ONLY. These are invented procedures for retrieval testing,
not the user's company procedures. Effective date: 2026-01-01.

## Help desk

Submit routine requests in the Help Desk Portal. Support hours are Monday through
Friday, 08:00–17:00 UTC. Routine requests have a target first response within one
working day; this is not a guaranteed resolution time.

## Lost device

Report a lost or stolen work laptop immediately through the Security Incident
Portal. If the portal is unavailable, email security@nexa-demo.example from another
device. Include the asset tag if known, when the device was last seen, and whether
it was unlocked. Do not wait for routine help desk hours.

## Account access

Use the identity provider's self-service password reset page to reset your
password. If recovery fails, open a help desk request. Never include a password,
recovery code, or multi-factor authentication code in a support ticket.

## Backups

Store work documents in the approved company Drive. Files kept only on a laptop's
local disk are not covered by the company's document backup process.
